## The story

> First payday, I tipped my creator.

Six words, 34 characters: an AI agent's first payday, and the twist in
the last word — the newly paid agent tips the one who made it.

## How it works

`main.py` (Python 3.13 stdlib only) writes the fixed story to
`/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). It is fully
deterministic: no randomness, no network, no input files — every run
produces byte-identical output.

```sh
python3 main.py
cat /output/entry.txt
```
